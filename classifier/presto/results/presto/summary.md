# Presto classifier: results

Generated by `presto_train.py`. Split: 127 labeled field-years (2017-2023, 96 Grain, 31 Silage, 64 fields) into train/validation/test by field (train 85-88, validation 19-21, test 19-21 field-years per seed), the same splits as the Prithvi classifier. Monthly inputs used: January to Dec. Each seed chooses its candidate on validation log loss; the test part is scored once for that candidate and for the hand-feature logistic baseline fitted on the same training part. Correct counts use a 0.5 cut.
